YönetimShop'u aç

Bu cihazı bağla

Shop'u bu telefondan yönetebilmek için bir kez GitHub anahtarı girilir. Anahtar sadece bu cihazda saklanır.

  1. GitHub'da Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → marka22-shop.
  3. Permissions → Repository → Contents: Read and write.
  4. Oluşan anahtarı kopyalayıp aşağıya yapıştır.
